# Мои книги — план проекта

## Зачем

Свой сайт вместо Notion «Book tracker»: красивее, с сериями, фанфиками и нормальной статистикой.
Notion импортируется один раз, дальше всё ведётся только в приложении.
Потом — PWA для iPhone (иконка на экране «Домой»), бесплатный хостинг.

## Решения

- Python (FastAPI), база Supabase (Postgres), бесплатный хостинг.
- Пользователь пока один, но данные уже разделены по пользователям — потом можно пустить других.
- Обложки и данные книг — из Hardcover; если нет — своя обложка по ссылке на картинку.
- Фанфики — только ficbook: по закладке в браузере (сервер ficbook блокирует).
- Серии: основные книги считаются в прогресс, повести (1.5) — отдельно «Дополнительно».
- Дизайн — со скиллами impeccable + frontend-design; цвета графиков проверять скиллом dataviz.

## Сделано

- Схема базы, привязка к пользователю, фанфики (миграции 001–007, все запущены в Supabase).
- Импорт из Notion: книги, фанфики, авторы, серии, описания серий (`notion_export/import_missing.sql`).
- «+ Добавить → Книгу»: поиск в Hardcover, добавление вместе с серией; вручную, если в Hardcover нет.
  «+ Добавить → Фанфик»: закладка для ficbook.
- «Найти в Hardcover» → «Связать»; «Обновить из Hardcover»; «Найти обложку» (Hardcover, Open Library, Google Books) или своя по ссылке.
- Вход по паролю (`APP_PASSWORD`), хостинг Render (`render.yaml`), PWA: иконка на экране «Домой».
- Дизайн «Spooky Book Universe» (подробно — ниже и в памяти Claude):
  - **Главная**: «Читаю сейчас»; доска «Мой книжный год» (плитки ≥150px, приведения);
    полка-шкаф: «Любимые» (любимая серия — целиком), «Читаю» (+ стопка книг и приведения), «Следующие».
    Корешки нарисованные, перетаскиваются, порядок сохраняется (`shelf_order`).
  - **Книги / Фанфики**: фильтры кнопками (статусы, «Следующие», «Избранное»), поиск, `?q=` из ссылки на автора.
    Карточка 196×373, обложка во всю ширину (180×270), серия/пейринг — плашкой на обложке.
  - **Серии**: фильтры, «Избранное», 4 обложки в карточке + «+N».
  - **Серия**: слева название, автор и книги, справа полное «О серии»; огонёк избранного в углу.
  - **Книга** (редизайн 28.10, коммит b174d86): обложка 220px слева; справа светлый полупрозрачный блок названия —
    тянется до низа обложки; справа сверху «ficbook» / «Где читать» и огонёк; внизу цветные факты
    (страницы, слова, части, дата, статус работы) и серия плашкой с корешками. Под ним без рамки: статус с иконками,
    «Читать следующей» (только у «Хочу прочитать»), капсула календаря «начало / конец», звёзды 1–5 справа.
    Ниже во всю ширину: описание (светлый блок, вкладки «Аннотация / Подробнее», сворачивается) и метки без рамки
    тремя колонками с заголовками — жанры (обводка) / настроения (заливка) / предупреждения (красный пунктир) по 3 + «+N».
    «Настройки книги»: ссылки, обложка, мой жанр, название в оригинале и на русском, заметки,
    история прочтений, **метки** (по одной на строку), **удаление** книги.
  - **Статистика**: год кнопками; две колонки (слева «По месяцам», «Оценки», «Объём»; справа «Жанры», «Авторы»),
    у каждого графика своя пастельная гамма, «Год за годом» клетками.

## Дизайн — как работаем

- Варианты делаем прямо на локальном сайте (`scripts/dev_fake.py`, http://127.0.0.1:8011): временный переключатель
  вида над страницей (`data-layout` + localStorage), после выбора — переключатель и лишние варианты убрать из кода.
- Свои идеи пользователь присылает схемой из символов (`| обложка | название |`) — читается хорошо, так и рисуем.
- Figma: файл https://www.figma.com/design/T6kzeO6MV7t2mUm34iPhDg (там «Сейчас на сайте» и «Компоненты» — иконки,
  метки, цвета-переменные; варианты A/B/C она удалила). Коннектор Figma на её плане Starter — **до 20 вызовов в месяц**
  (whoami и create_new_file не считаются), октябрьские потрачены; когда сбрасывается — Figma не пишет.
  Автораскладку в Figma она двигать не умеет — если строить там, то свободными рамками без автораскладки.

## Дизайн — пожелания

Название — **Spooky Book Universe**, талисман — приведение (static/img/booky/).
Концепт главной: https://claude.ai/artifact/TqTCNq2JxXexM7JoewGgdc
Референсы — в `refs/` (в git не попадают). Персонажи `refs/people1–3.png` пользователь сгенерировала сама — можно использовать.
Шрифт — не обязательно как в макете. Элементы — ярче и разнообразнее.

**Общее**
- Фон светло-сиреневый (в сторону #9400D3, но не однотонный), круглые блики «как от солнца».
- Пастельные цвета, разноцветные карточки-окошки.
- Персонажи в духе doodles: книжки-человечки, драконы, единороги, сказочные. Не копировать Doodles — похожие свои.
- Размытые (blur) обложки на фоне.

**Главная** (макет — refs/home.jpg)
- «Читаю сейчас», доска, полка. «Серии сейчас» убран — и так видно в «Читаю сейчас».
- Хаотичная разноцветная доска: в этом месяце, всего прочитано, серий закончено, фанфиков за год, лучший месяц года.
  Цифры должны выделяться сильнее картинок — не сливаться в один ком.
- Без блока фанфиков и без «Хочу прочитать».

**Страница книги** (как на Hardcover) — сделана 28.10, см. «Сделано»
- Статус, даты и оценка — справа от обложки, под названием, без рамки. Подписи дат — только «начало / конец».
- Отвергнуто: «моё» столбиком под обложкой, обложка справа, тёмные и пастельные блоки, даты плашками.
- Меню статуса: у каждого статуса своя иконка и свой цвет; оценка звёздами прямо в меню.
- Жанры и настроения (moods) — «пилюлями» с иконками, moods цветные.
- Блок распределения оценок (Ratings N, Average, столбики 1–5★) — решить, откуда брать цифры.
- Статусы «На паузе» и «Брошено» остаются.

**Страница серии**
- Слева название, автор и книги серии, справа полное описание серии.

**Полка**
- Три полки, по одной доске; корешки нарисованные (корешки из обложек пробовали — не понравилось).
- Приведения вокруг шкафа и на полке «Читаю».
