Добавить фанфик

Открой фанфик на ficbook и нажми закладку «В мои книги» — форма заполнится сама. Или заполни вручную.

Для переводов «Оригинал | Перевод» — разделится на два названия, как в Notion.

Фанфик добавится в «Хочу прочитать». Если он уже есть — обновятся данные с ficbook, твой статус и оценка не изменятся.

Как поставить закладку «В мои книги»

На компьютере: перетащи эту кнопку на панель закладок → 📚 В мои книги

На iPhone (Safari):

  1. Добавь в закладки любую страницу (Поделиться → Добавить закладку), назови «В мои книги».
  2. Скопируй код ниже кнопкой «Скопировать».
  3. Открой закладки → «Изменить» → эта закладка → вставь код вместо адреса.
  4. На странице фанфика: нажми на адресную строку → выбери закладку «В мои книги».

Адрес приложения зашит в закладку. Когда приложение переедет в интернет, закладку нужно будет обновить с этой страницы.

iPhone: «Поделиться → В мои книги»

Быстрая команда: на странице фанфика в Safari жмёшь «Поделиться» → «В мои книги», и открывается эта форма уже заполненной.

Важно: телефон должен видеть приложение по адресу {{ base }}. Адрес localhost / 127.0.0.1 с телефона не откроется — команда заработает, когда приложение будет в интернете (хостинг) или в Codespaces с APP_BASE_URL.

  1. Настройки iPhone → Быстрые команды → Дополнения → включи «Разрешить выполнение скриптов».
  2. Приложение «Быстрые команды» → «+» → назови «В мои книги».
  3. Нажми ⓘ (или «Настройки» внизу) → включи «Показывать в меню „Поделиться“» → типы: только «Веб-страницы Safari».
  4. Добавь действие «Запустить JavaScript на веб-странице» → удали пример и вставь код ниже (кнопка «Скопировать»).
  5. Добавь действие «Открыть URL-адреса» — оно само возьмёт результат предыдущего шага.
  6. Готово. На странице фанфика: «Поделиться» → «В мои книги». В первый раз iPhone спросит разрешение для ficbook.net — «Разрешить всегда».

Если адрес приложения поменяется — скопируй код заново и замени его в команде.
